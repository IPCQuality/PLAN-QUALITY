# PWA Assets & Configuration

Folder ini mengelompokkan seluruh aset dan konfigurasi Progressive Web App (PWA):

- `manifest.json`: Web App Manifest berisi metadata aplikasi, warna tema, display mode, dan ikon.
- `sw.js`: Service worker untuk penanganan cache dan siklus hidup PWA.
- `icons/`: Kumpulan ikon resolusi tinggi:
  - `pwa-192x192.png`: Ikon standar resolusi 192x192 px.
  - `pwa-512x512.png`: Ikon standar resolusi 512x512 px.
  - `pwa-maskable-512x512.png`: Ikon maskable dengan safe margin untuk Android.
  - `apple-touch-icon.png`: Ikon Apple Touch untuk iOS Safari home screen.
